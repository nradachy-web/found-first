What should ERP onboarding AEO say about opening balances?

If your ERP onboarding offer includes loading opening balances, spell out who delivers a balanced file and who accepts the result. That distinction lets a controller judge whether the finance team can handle cutover with the services on offer.

Trace the balance from ledger to signoff

Use the implementation scope and the import workbook together. The scope establishes who performs each task. The workbook shows what that person has to produce, such as a balance by account, entity and currency at the agreed close. A blank file marked “opening balances” tells a buyer very little about the accounting work involved.

Answer the question behind the launch date

A controller may be asking whether the old ledger must close before the new one opens for posting. Show which approval releases the import and who handles late adjustments. Where the answer depends on the cutover agreement, identify the decision the buyer needs to make with the implementation lead.

The file loads, but the totals disagree

Imagine the sample statement of work assigns account mapping and reconciliation to the customer. The vendor runs the import and returns an exception report. An AEO page based on those documents should tell buyers to reserve a controller for reconciliation before authorizing live posting. If a signed partner scope includes reconciling the trial balance, the page can instead explain which working papers the partner prepares and which totals the controller still approves.
