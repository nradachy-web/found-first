AEO for tile retailers selling mixed-pattern cartons

A tile retailer should use AEO to answer what the pattern selector actually buys. A named collection, a photo of one decorative face and a carton with assorted faces can all appear on the same page. A buyer planning a repeating border needs to know which of those choices carries through to the order.

Give the gallery and the order line different jobs

Label the gallery so a shopper can see the range of designs. Then use the supplier's carton description to explain whether a particular face can be ordered and whether the mix is specified. A display board arranged by a stylist is a poor basis for promising a particular sequence in the box.

Answer quantities only where the pack supports it

If a carton has a documented face-by-face breakdown, reproduce the relevant counts beside its order code. If faces are assorted without a fixed breakdown, say whether the retailer sells named faces individually. Ordering more mixed cartons cannot assure a run of the exact motif a customer wants.

A star tile for a continuous border

Suppose a showroom board features a star motif and the manufacturer's packing sheet describes the cartons as assorted with no guaranteed face. A shopper wants stars all the way across a backsplash. The carton page should explain why the pictured star cannot be specified. If a separate catalog line sells that star by the piece, point to that order line for the border and reserve the mixed carton for shoppers who like the range.
