When repeat inquiries from ChatGPT ads count as one lead

For a ChatGPT ads lead report, count the underlying buying request once even if it arrives through several forms. Keep all the messages attached to that request so sales can answer the newest details and marketing can still investigate repeated submissions.

Match the work the buyer is requesting

An email address is a starting point. Compare the requested item, delivery site, project reference and timing before combining records. Different employees may ask about the same purchase. Equally, a purchasing manager can use one inbox for several independently approved jobs. A blanket rule that merges everything from one domain loses the second kind of demand.

Check what the quote would cover

Ask the rep whether fulfilling the open quote would satisfy both inquiries. A correction to dimensions can live on the first opportunity. A separate order with its own approval and destination can merit another opportunity even with the same contact. Keep customer counts separate when you need to know how many distinct buyers you acquired.

A revised drawing reaches a second form

Suppose a sign maker receives a brochure request and then a quote form with a revised drawing. Both identify the same lobby and purchase reference. The rep attaches the revision to the open quote, and the marketing manager counts one lead in the campaign review. If the new drawing names a different property with its own approval and installation order, the rep opens another opportunity. The customer count still reflects a single purchasing organization.
