AEO for core returns on remanufactured auto parts

Give core returns a dedicated answer if your parts shop expects the buyer to send the old unit back after installing a remanufactured one. A standard merchandise return page can lead the buyer to ask for a refund on the replacement they intend to keep.

Show which unit goes in the box

Use the names on the invoice to distinguish the replacement from the old unit the shop calls a core. Check the supplier's acceptance sheet before describing required components, identifiers and packaging. A generic instruction to return “the original” is particularly confusing when the shop wants the old unit in the replacement's shipping carton.

Explain what tracking can establish

Link the return authorization to the order and explain who records acceptance. A carrier's delivery scan can answer whether the parcel arrived. If the shop issues credit after inspection, specify where a buyer can check that decision and what order details support needs to trace a delivered core.

An alternator with a different housing

Suppose a rebuilder's acceptance sheet calls for an alternator from the exchange family on the invoice. The buyer compares the old unit with the sheet and finds a matching housing code. The shop's answer can direct them to use the core label and retain the tracking reference. If a previous repair left the vehicle with a different housing, send the stamped code to the parts desk first. Mailing it under the standard label would leave its acceptance unresolved.
