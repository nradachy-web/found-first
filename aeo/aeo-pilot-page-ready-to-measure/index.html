When is a revised page ready to measure in an AEO pilot?

Start the post-edit observation period when the intended public page serves the approved answer in the context a buyer needs. Record that point as the release of the page. Whether an answer service has picked up the revision is a separate finding.

Check the buyer's version

Follow the link a buyer would use from the offer page, without an editor login. Read the condition, exception and next step on the destination. Keep the public address and a dated copy of the passage alongside the approval. A successful preview or a published announcement alone gives you too little evidence to start judging the revised answer.

Treat platform access as a separate check

For a pilot that covers ChatGPT search, have the site owner distinguish OpenAI's search crawler settings from its model-training crawler settings. A setting for the latter does not establish access for the former. For Google AI features, ordinary search requirements apply and meeting them does not assure inclusion. Neither check tells you the date an answer will reflect your edit.

The approved exchange policy is still in preview

Suppose a uniform supplier approves a new explanation of exchanges for embroidered garments. The editor can see it, but the product page still sends a signed-out visitor to the older policy. Fix the public link and save the first verified public version before treating observations as post-edit. If that link already reached the approved passage and a sampled answer still gave the old terms, keep the observation. The buyer could access the revision even though that answer did not reflect it.
