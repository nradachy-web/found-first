Can you compare AEO pilot results after the test questions change?

Compare results only for questions that asked the same buying question under comparable conditions. Keep any newly introduced need in the report as a starting point for future work.

Recover the original test

Ask for the actual question and answer from each review. A spreadsheet label such as delivery terms can conceal changes in geography, order type or urgency. Also check the service used and whether the answer came from a fresh conversation or a follow-up that already supplied facts. Match observations on the conditions that could change the answer.

Show where the comparison ends

Report what happened on the matched questions, then identify which questions were added, retired or materially rewritten. If the old record contains only a combined score, you may have no way to recover a comparable subset. Use the new set as a baseline and leave the direction of change open. A valid new question can be worth measuring even when it breaks the old comparison.

A delivery question acquires a loading dock

Imagine a packaging supplier's original test asked whether pallet orders could be delivered to a site without a dock. The closing review asks only whether the company delivers pallets. The new answer names the supplier, but it never has to resolve the liftgate condition that made the first question difficult. Keep the broad answer for future comparison and repeat the original question for the pilot review. If both saved questions had specified a site without a dock and differed only in punctuation, the team could compare the answers directly.
