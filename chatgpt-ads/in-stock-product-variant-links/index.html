ChatGPT advertising · Landing page decisions after the ad

Where should ChatGPT ads land for an in-stock product variant?

For a ChatGPT ad featuring a particular size and finish, link to the page state that selects that exact combination. Use the wider product family when the ad gives shoppers a genuine choice across the family.

Check what survives the link

Open the destination in a fresh browser session. Read the selected options, availability message and cart line after adding the item. A photo of the advertised finish can stay on screen while the option selector silently defaults to another. Match the cart description against the item your fulfillment team would pick.

Decide what happens at sellout

A visitor with an older link should see which combination sold out and which alternatives they can choose. Keep the original selection visible long enough to explain the change. If the only available option differs on a feature named in the ad, hold or revise the ad before buying more visits to that page.

The left-hand return on a writing desk

Imagine a furniture retailer whose ad features a walnut desk with a left-hand return. The inventory record lists the two return orientations separately, but the product page opens on the right-hand desk. A link that selects the left-hand version and carries it through to the cart fits the offer. If that version sells out, the page can show the right-hand model as an explicit alternative. A family-level ad showing both layouts could still use the selector.
