ChatGPT advertising · Campaign diagnostics and reporting

Did an edit cause the drop in ChatGPT ads impressions?

Check whether the fall in ChatGPT ads impressions started before the edit you are being asked to reverse. If it did, rolling back that edit cannot address the original onset, though a later effect is still possible.

Put the change on the delivery timeline

Retrieve the dated record of the actual edit. A draft approval can precede the live change. Match its time zone to the delivery records and use the finest interval both records support. A daily total that straddles an afternoon edit leaves the sequence within that day unresolved. Mark that interval as ambiguous instead of classifying the whole day as exposed to the change.

Look for a meaningful comparison

Check whether an unaffected campaign with a similar schedule also lost impressions during the same period. A shared decline warrants looking beyond the edit. A decline confined to the changed campaign makes the edit worth investigating, especially if no other documented change coincides with it. Timing alone is weak grounds for a permanent reversal.

An updated tour description

Say a venue revises the description in its tour ad and sees fewer impressions on the weekly chart. Its publication email places the revision on Thursday. Daily counts show the fall began Tuesday, so the manager keeps the accurate description and investigates Tuesday's delivery. If the first decline instead appears after Thursday and a comparable, untouched tour campaign holds steady, the manager considers a controlled comparison with the earlier wording, provided it still describes the tour accurately.
