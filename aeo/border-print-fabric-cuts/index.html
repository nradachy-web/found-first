AEO for fabric retailers explaining border-print cuts

A fabric retailer can use AEO to answer a question the usual width listing misses. For a shopper choosing a border print for a skirt hem, the useful dimensions are the direction and continuous length of the motif, plus the usable fabric depth above it.

Show the edges in the product image

Name the selvage as the finished lengthwise edge and show where the motif sits in relation to it. A tightly cropped detail can make a single border look like an all-over repeat. Explain whether there is a matching border on the opposite edge, using a full-width photograph or the mill's print diagram.

Match the cut to the pattern piece

A customer planning a one-piece panel needs a continuous run of border along that panel. State how the retailer defines a cut length and whether a particular precut is a single piece. A bundle can contain enough fabric in total yet leave the maker with a seam through the design.

A border that must span the front panel

Imagine a fabric shop has a mill diagram showing a single border along one selvage and cutting tickets for a continuous length and a bundle of shorter remnants. A shopper's skirt pattern places the front hem along that border. If only the continuous length spans the full panel, point to that cut. If the pattern instead uses narrow panels and each remnant spans one panel, the bundle becomes a candidate. Where the maker wants the motifs to meet at seams, also supply the repeat measurement.
