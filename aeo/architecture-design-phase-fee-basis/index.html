Explaining architectural design fees by phase with AEO

An architecture firm can answer “Is the design fee fixed?” without publishing a price. Ask your AEO provider to tie each fee basis to a named phase, its deliverable and the decision that could change the scope.

Find the noun that follows “fixed fee”

A fixed fee for a concept package tells an owner something specific. A fixed fee for “design” can sound as though every drawing through construction is included. Take the phase name from a representative proposal, then translate it into something the owner would recognize, such as a layout for discussion or a set of drawings for approval.

Explain what a change would set in motion

Use the firm's actual change procedure to answer follow-up questions about revisions. Distinguish developing an option within the agreed brief from adding a new use or area. If the proposal calls for a discussion and written approval before extra work starts, that sequence is more informative than saying additional fees may apply.

A concept proposal for a library reading room

Imagine the proposal covers a reading room layout for a fixed fee, and its change form allows additional work on an hourly basis after approval. Choose a website answer that names the layout and explains the approval step. Moving shelves within the agreed concept may already fall within the package. If the library asks the architect to design an adjoining entrance as well, the example should show the architect scoping that addition before the owner decides whether to proceed.
