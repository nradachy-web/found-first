GEO for photo archives when AI promises a downloadable scan

A photo archive should flag an AI answer that promises a downloadable file on the strength of a catalog thumbnail. The GEO decision is whether the record for that photograph gives a researcher a reliable next step after they follow the link.

Inspect the item behind the collection link

A collection page might advertise digital copies while individual records describe prints that still need scanning. Check whether the cited material names the item, indicates its format and explains how to obtain it. The assistant that links closest to the item may provide the most practical evidence, even if another answer gives a more detailed account of the collection’s history.

Use a public record to explain access

A useful public record can say “reference image online” and identify the route for requesting a reproduction. The full-resolution file can remain in its existing delivery system. If a GEO proposal recommends opening that system to improve ChatGPT discovery, ask what is missing from the public record first. OpenAI distinguishes search crawling from model-training access.

A harbor panorama in a digitized collection

Imagine an archive with a collection overview labeled “digital photographs” and a harbor panorama whose record shows a cropped preview. One assistant links to the overview and promises an immediate download. Another finds the item record, which has a scan request form. For a print awaiting digitization, label the preview and keep the request route visible. If the full scan already exists and the record mistakenly points to the request form, restore the download link for that item.
