GEO for equipment makers when an older manual is cited

Keep an older manual available when customers still use that model. The reason to fund a GEO correction is a mismatch between the revision cited and the equipment a prospective buyer would actually receive.

Establish which unit the question describes

Record the product name in the question, the revision identified in the answer and the model currently shown on the order sheet. A question about servicing an installed unit can legitimately lead to a discontinued revision. A question about a new order calls for evidence about the unit shipping under that name.

Give the old document a precise job

Check the manual's cover and download listing for a readable model identifier. If the marketing name spans revisions, ask for a public explanation of which manual applies to which unit. Keep a dated copy of the order sheet with the review so a future catalog change doesn't alter the basis for the decision.

One balance name, two power supplies

Imagine a lab supplier whose bench balance kept its trade name after switching from removable batteries to mains power. A saved answer tells a new buyer to pack spare batteries and cites the earlier manual. If the order sheet offers only the mains model, approve revision labels and a current-model link beside the download. If buyers can still select either unit as refurbished stock, show the power supply beside each orderable model and assess each answer against the selected unit.
