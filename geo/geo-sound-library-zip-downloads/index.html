GEO for sound libraries sold as ZIP downloads

If your sound library ships as a ZIP file, publish a readable description of the files a buyer will receive. For GEO, the most valuable addition may be a short list that distinguishes separately editable recordings from sounds heard only in a preview mix.

Describe the unit a buyer can use

An audio producer asking for isolated ambience needs to know whether they can place that sound on its own track. A convincing demo can contain effects, narration and music that are absent from the download. Give the public file list plain descriptions and identify any preview-only layers where visitors hear the demo.

Build the list from the delivery archive

Inspect the ZIP prepared for customers, since a production folder can contain unused takes and working files. Group equivalent variations where that helps a buyer scan the list. Preserve distinctions that affect editing, such as an isolated take, a continuous loop or a finished stereo mix.

Rain under a station announcement

Suppose a publisher’s railway ambience preview plays rainfall beneath an announcement. The delivery archive contains a station mix and a separate rain loop. A public file list can promise the isolated rain loop and describe the announcement as part of the station mix. A producer who needs the voice alone can now rule the pack out before downloading it. If a separate announcement recording is later added to the archive, revise the list for that edition and identify which sample demonstrates the new file.
