Should a GEO team replace last year's research report?

Keep a cited edition available at its established address when a new report comes out. Give buyers looking for the latest edition a series page that names the current release, the period it covers and the earlier editions.

Give each link a clear job

A link labeled latest report can reasonably lead to the newest edition. A link supporting a specific historical finding needs to lead to the edition that contained it. Ask your GEO editor to follow a citation from last year's press coverage. Can a reader arriving there still find the exact table and its definitions?

Make a decision about the trend line

A new edition can answer the same business question using a different measure. Before approving a year-over-year sentence, compare the question text, eligible population and reporting unit. If a definition changed, a note at the point of comparison can explain where the old series ends.

A design survey changes its unit

Suppose a publisher's earlier design report counted studios offering remote consultations. The new tables count individual designers offering them. A GEO editor links both editions from the series page, labels each unit and declines to describe the difference as growth. If the researchers can recompute the earlier result by designer using compatible underlying records, the editor can publish a labeled comparison with that recalculation. A reader following an old press citation should still reach the originally published studio figure.
